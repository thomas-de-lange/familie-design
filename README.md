# familie-design

Logo und Hintergrund der Familie de Lange, öffentlich abrufbar für Seiten, die ein Bild über
eine URL einbinden.

| Datei | Inhalt |
|---|---|
| `logo.png`, `logo.svg` | Logo „Die Drei“ auf Schiefer |
| `hintergrund.png`, `hintergrund.svg` | Hintergrund „Höhenzüge“ |

Farben: Schiefer `#2B3437`, Kalkweiß `#FBFAF4`, Fensterladen `#2F6647`, Weide `#86AE50`,
Heu `#E3A93B`.

Die Bilder sind erzeugte Kopien, hier nicht von Hand ändern.
